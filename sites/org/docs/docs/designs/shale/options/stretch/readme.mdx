---
title: 'Fit Waist (Stretch)'
---

When this option is at 0%, which is the default, Shale will fit the waistband to the
seat circumference, so you can wear the shorts using non-stretchy fabric without
an additional opening.

In case you want to use stretchy fabric or add an opening, you can increase the
value of this option. At 100%, the waistband will match your approximate body
circumference at waistband height.
